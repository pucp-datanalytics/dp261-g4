# Cargas locales de usuario

Esta carpeta queda preparada para archivos cargados desde el dashboard.

- No guardar aqui datos sensibles.
- Los archivos cargados por usuarios son locales y no deben versionarse.
- El dashboard mantiene el dataset oficial `docs/dataset_pucp.csv` como fallback reproducible.
- Las copias validadas y predicciones se generan en `data/processed/` con prefijo `c_`.
